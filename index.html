Aparência e comportamento

Privacidade

Seus dados ficam armazenados neste dispositivo e não são enviados para servidores externos. Para transferir entre iPhone e iPad, use o backup manual.

Backup e segurança

Exporte uma cópia completa dos registros. Anexos são incluídos como Base64 quando possível.

Recomendação: salve o backup no iCloud Drive. Os dados locais não são sincronizados automaticamente entre aparelhos.

Instalar aplicativo no iPhone/iPad

  1. Publique este arquivo em um endereço HTTPS.
  2. Abra o endereço no Safari.
  3. Toque em Compartilhar.
  4. Escolha Adicionar à Tela de Início.
  5. Confirme o nome e abra pelo novo ícone.
Como esta entrega usa somente um arquivo HTML, ela não inclui manifest.json nem service-worker.js. Portanto, não é tecnicamente uma PWA offline completa. O Safari pode manter cache, mas o funcionamento offline após fechar/reabrir não deve ser tratado como garantido sem esses arquivos adicionais.

🔒 Etapa obrigatória

Configure o essencial

Antes de entrar no aplicativo, preencha os dados essenciais. Eles são usados nas estimativas de TMB, TDEE, hidratação e acompanhamento da evolução. Depois você poderá editar tudo nas Configurações.

Se você já tem os valores de massa muscular e massa de gordura da sua avaliação, informe-os aqui. O app usará esses dados nos gráficos de composição corporal.

Estimativas não substituem acompanhamento profissional.
